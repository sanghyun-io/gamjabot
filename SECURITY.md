# Security

This is an experimental source snapshot. No release or platform is currently designated as a supported security-maintenance version. Do not rely on it for sensitive workloads.

Please do not report suspected vulnerabilities in public issues, pull requests, discussions, or logs. Use the repository's **Report a vulnerability** option under the Security tab when private vulnerability reporting is enabled: [private vulnerability reporting](https://github.com/sanghyun-io/gamjabot/security/advisories/new). If that option is unavailable, do not post the details publicly; a private reporting channel has not yet been confirmed. Do not include API keys, tokens, passwords, personal conversations, payment data, or raw databases. Share a minimal synthetic reproduction, affected revision, impact, and a safe way to contact you through the private report.

Reports are reviewed on a best-effort basis; no response or fix timeframe is currently guaranteed.
