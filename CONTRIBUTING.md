# Contributing

Thanks for helping improve this experimental source snapshot. Open a public issue for a non-sensitive bug or proposal before a large change so its scope can be discussed. For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead.

Keep changes focused and describe the problem, approach, affected platforms, and any compatibility implications. Include relevant tests where feasible and report exactly what you ran, the environment, results, and any checks you could not run. Do not claim installation, native behavior, provider access, or security validation from source review alone. The source snapshot does not yet have a verified, complete public build/run recipe; platform-specific signing and packaging may require additional work.

Use synthetic fixtures only. Never submit credentials, personal conversations, user databases, browser profiles, payment information, private logs, or other private data. Inspect diffs and generated files before posting. Avoid attaching raw diagnostics; summarize the relevant behavior with sensitive information removed.

By submitting a contribution, you agree to license it under the project's Apache-2.0 license and confirm you have the right to submit it. Maintainer capacity and response times are not guaranteed.
